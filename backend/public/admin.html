📚 GUIDE DES RISQUES EXPLIQUÉS
1. Brute Force (Force Brute)
Un pirate essaie de deviner ton mot de passe en testant des milliers de combinaisons.
Défense actuelle : Bloqué automatiquement après 5 essais (Rate Limiter).
2. Injection SQL
Un pirate entre du code malveillant dans un champ de recherche pour voler la BDD.
Défense actuelle : Requêtes préparées (PostgreSQL $1, $2). Le code est neutralisé.
3. Lockdown Protocol
Si tu penses que le site est piraté, active le Lockdown. Toutes les actions d'écriture (commandes, ajouts) seront bloquées pour protéger tes données le temps de trouver la faille.
